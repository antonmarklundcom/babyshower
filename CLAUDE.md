# CLAUDE.md

Static HTML site (babyshower.com.py) generated by Node 22, plus one PHP endpoint. Hostinger
deploys `master` by cloning the repo, so there is no server-side build. See `README.md` for the
repo map and `docs/DEPLOY.md` / `docs/HOSTINGER-GIT.md` for deployment.

## Commands

- `npm run build`: `node build-site.mjs`
- `npm run verify`: `node verify.mjs --phase B5`
- `npm run verify:final`: `node --test verify/*.test.mjs` (same checks as `node verify.mjs --final`)
- `npm run preview`: local static preview on port 4173
- `npm run smoke`: `node deploy/smoke.mjs` (GET only, against the live site)
- `npm run css-audit`: `node css-audit.mjs`
- `npm run php:lint`: `php -l lead-forward.php`
- `npm run php:test`: `node docs/qa-tools/php-endpoint.mjs`
- `npm run check`: build + verify:final + php:lint + php:test (run before every commit)

## Rules

- Generated files: never hand-edit `*/index.html`, `404.html`, `gracias.html`, `sitemap.xml`
  or `lead-defaults.php`. Change the source (`content.mjs`,
  `themes.mjs`, `zones.mjs`, `ideas.mjs`, `build-site.mjs`, `build/`, `assets/`) and run `npm run build`.
- Generated output is committed. Rebuild before commit and keep `git status` clean (no stray
  rebuild diffs left behind).
- No secrets: no API keys, tokens, emails or real lead data in code, docs or fixtures. The real
  VenderCRM config stays above `public_html`, never in the repo.
- No new dependencies: no `package.json` dependencies, nothing may need `node_modules` on the server.
- Site copy is es-PY voseo (Spanish for Paraguay). New docs are written in English.
- Do not change prices, the WhatsApp number or `PRICES.effectiveDate` unless asked.
- Codex worker process (manager/worker dispatch prompts): see `AGENTS.md`.
