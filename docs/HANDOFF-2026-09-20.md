### Important finding about Lighthouse
The earlier "97 to 99" does not reproduce on this laptop with the plain preview server: it scores **89** (also on the commit before the reskin). Cause: the server sent text uncompressed and Lighthouse simulates slow 4G from bytes on the wire. With compression on, the same page scores 99. Real Chrome paints the page in 110 to 220 ms either way. `preview-server.mjs` now compresses (brotli/gzip) and `.htaccess` has DEFLATE and Brotli blocks. **Measure Lighthouse only against `preview-server.mjs` from this repo, and confirm on the real host that `Content-Encoding` arrives.**

## 5. Environment facts learned tonight (they cost time)

- `preview-server.mjs` takes its port from the **`PORT` environment variable**, not argv. `.claude/launch.json` passes `8095` as an argument, which is ignored, so the server binds 4173 (possibly already used by another window). Use `PORT=4185 node preview-server.mjs`.
- **Never use port 4190** for Node tooling: it is on the fetch blocked-ports list ("bad port"). curl and Chrome work, Node `fetch` (and so `verify.mjs --http`) does not.
- Screenshots in the Claude browser pane time out often. Use `node docs/qa-tools/shots.mjs <url> <width> <prefix> [sliceHeight]` (Playwright plus installed Chrome), then read the PNGs in `docs/qa-tools/out/` (gitignored).
- Lighthouse: `CHROME_PATH="C:/Program Files/Google/Chrome/Application/chrome.exe" npx --no-install lighthouse <url> --only-categories=performance,accessibility,seo,best-practices --form-factor=mobile --output=json --output-path=<file> --chrome-flags="--headless=new --no-sandbox" --quiet` (a Windows temp-cleanup stack trace at the end is harmless; read the JSON).
- `deploy/make-zip.ps1` needs `-ExecutionPolicy Bypass`. PHP, `rg` and Python are not installed.
- Prompts for Codex must be ASCII with no double quotes (the `.cmd` wrapper and PowerShell stdin garble accents); describe accented strings in words and tell Codex to write the accents. The wrapper skill is `~/.claude/skills/manager-worker-codex/scripts/codex-run.ps1`.
- The other window's Fable may keep a server on 4173; do not stop it.
